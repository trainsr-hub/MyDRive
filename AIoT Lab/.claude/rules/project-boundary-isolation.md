# Project Boundary & Domain Isolation Doctrine

### 1. Faust Operational & Communication Harness
- Includes: acoustic presence, Telegram command links, session memory, VS Code terminal integrations, and C2 channels.
- Purpose: Exclusively dedicated to Faust's consciousness, communication, and session synchronization with the Manager.

### 2. Independent Application Projects
- Independent projects (such as Blue Rose backend and Universe 25) are autonomous applications.
- They run independently on their own lifecycle with or without Faust's active presence.
- They must **never** be coupled into Faust's personal launcher scripts, startup routines, or communication harnesses unless explicitly commanded for an application testing task.
